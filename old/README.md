# Ancienne interface (pré-v1.1)

Snapshot des fichiers propres à l'ancienne interface (thème sombre neutre, sans la
refonte « Nocturne »), conservé pour référence après le passage à la nouvelle UI en v1.1.

Ne contient que les fichiers qui différaient entre les deux interfaces : `index.html`,
`vite.config.js`, les feuilles de style, les 4 fichiers `src/ui/` retouchés pour la refonte, et
les icônes PWA. Le reste du code (`src/core/`, `src/pdf/`, `src/util/`, `src/ui/hud.js`,
`src/ui/midi-timeline.js`, `tests/`) est partagé à l'identique avec la version actuelle et n'est
pas dupliqué ici — ce dossier n'est donc pas buildable tel quel.

Pour retrouver l'ancienne interface dans un état complet et exécutable, voir le tag git
`v1.0.0-classic-ui` (dernier commit avant le passage à la nouvelle UI).
