# Exemples

`gamme-de-do.pdf` / `gamme-de-do.mid` — gamme de Do (do ré mi fa sol la si do) : main droite
seule, puis main gauche seule, puis les deux ensemble. Généré (partition + MIDI depuis la même
source, donc parfaitement synchronisés), pas une partition sous droits — pratique pour tester
l'app sans dépendre d'un vrai morceau.

Importer les deux fichiers dans la bibliothèque comme n'importe quel morceau.
